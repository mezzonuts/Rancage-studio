# Fix GitHub Pages 404 — Root Cause & Plan

## Root Cause

**Workflow file is in the wrong location.** GitHub Actions **only** looks for workflow files in the repo-root `.github/workflows/` directory. Currently the workflow lives at:

```
rancage-studio/.github/workflows/deploy.yml   ← WRONG (subdirectory)
```

It needs to be at:

```
.github/workflows/deploy.yml                  ← CORRECT (repo root)
```

The repo root is `D:\Project\Rancage\`, but `.github/` doesn't exist there — it only exists inside `rancage-studio/`. GitHub never sees the workflow, so the build never runs, so Pages returns 404.

Additionally, per the GitHub Pages docs, the user must:
1. Go to **Settings → Pages**
2. Set **Source** to **GitHub Actions** (not "Deploy from a branch")

## Fix Steps

### Step 1: Move workflow to repo root

Create `.github/workflows/deploy.yml` at `D:\Project\Rancage\.github\workflows\deploy.yml` (repo root). The existing content at `rancage-studio/.github/workflows/deploy.yml` can be deleted or kept as reference.

### Step 2: Verify `next.config.ts` has correct `basePath`

Current state:
```ts
basePath: '/Rancage-studio',
trailingSlash: true,
```

This is correct for a project repo named `Rancage-studio` served at `https://mezzonuts.github.io/Rancage-studio/`.

### Step 3: Commit and push

Commit the moved workflow file and push to `master`. This will trigger the workflow automatically.

### Step 4: User enables GitHub Pages

The user must manually:
1. Open https://github.com/mezzonuts/Rancage-studio/settings/pages
2. Under **Build and deployment → Source**, select **GitHub Actions**
3. Click **Save**

### Step 5: Verify deployment

After the workflow completes (~2-3 min):
- Site should be live at `https://mezzonuts.github.io/Rancage-studio/`
- `https://mezzonuts.github.io/Rancage-studio/studio/` should show the app

## Files Changed

| File | Action |
|------|--------|
| `.github/workflows/deploy.yml` | **Create** at repo root (copy from `rancage-studio/.github/workflows/deploy.yml`) |
| `rancage-studio/.github/workflows/deploy.yml` | **Delete** (no longer needed) |

## Validation

2. Wait for green checkmark on workflow
3. Visit `https://mezzonuts.github.io/Rancage-studio/` — should show landing page
4. Visit `https://mezzonuts.github.io/Rancage-studio/studio/` — should show the app
